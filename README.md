# Campus Equipment Booking and Checkout

A lending system for Igire Rwanda's SheCanCODE bootcamp. Participants borrow training laptops and graduation gowns, and staff track each item from request to return.

- Request a laptop for a date range or a graduation gown in a given size
- Staff approve requests and assign a specific item, with no double bookings for the same item
- Record pickup and return, including condition and charger handover
- See which items are available, reserved, checked out, or on a cleaning hold
- Participants see only their own loans and due dates. Staff see overdue laptops and gowns that haven't come back.
